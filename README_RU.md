# Kotora Cat 1.3.0

Minecraft Java 1.20.1 + Forge 47.4.3/47.4.x + Java 17.

## Что изменено

- Kotora больше не наследуется от ванильного `Cat`: собственный AI, цели, бой и поведение.
- Криперы больше не пугают Kotora. Звук шипения сохранён.
- Kotora охотится на любых монстров, включая криперов, скелетов, зомби и т.д.
- Особая интеграция с Cracker's Wither Storm: Kotora постепенно входит в ярость и запускает команду `witherstormmod kill`, чтобы использовать штатную анимацию смерти Шторма.
- Два характера с вероятностью 50/50: **Добрый** и **Злой**.
- У характеров разные боевые маневры и текстуры.
- Рыба приручает Kotora с шансом 50%. После приручения можно посадить/отпустить кота пустой рукой.
- Кот следует за владельцем и возвращается к нему телепортацией при большой дистанции.
- Добавлен редкий случайный спавн Kotora в мире.
- Яйцо призыва имеет подсказку **«Wither Storm от Kotora»**.
- Сохранение характера, состояния приручения и прогресса атаки Шторма через NBT.

## Важно

Это исходный проект. Готовый JAR должен быть собран Gradle/ForgeGradle; этот набор файлов не является заранее скомпилированным JAR.
