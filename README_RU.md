# Kotora Cat 1.1.4

Исправлена модель и UV-текстура кота. Версия использует собственную модель `KotoraCatModel` и собственную квадратную PNG-текстуру 64x64, поэтому фото больше не вставляется в UV-развёртку ванильного кота.

Сборка: Minecraft Java 1.20.1 + Forge 47.4.3 + Java 17.

Механика Wither Storm из 1.1.3 сохранена.
